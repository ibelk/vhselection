VH Selection — Інформаційна архітектура

Знімок IA на основі sitemap.md і flows.md. Повний текст з усіма джерелами — у цих двох файлах; ця сторінка лише збирає їх в один погляд.

Sitemap

3 групи, 4 екрани. Дерево — за розділом «Екрани» в sitemap.md; жодного екрана поза реєстром.

  • Вхід
    • Головнийглобальний home.html
      Job: Main — «дійти до реальної домовленості про експорт через перевіреного партнера» (+ контент, що підтримує R2/E1/S1). Персона: Primary і Secondary.
  • Каталог
    • Список виноробеньглобальний catalog.html
      Job: R1 — «звузити вибір до реально підходящих партнерів» (+ E2). Персона: Secondary.
    • Картка виноробніконтекстний winery.html
      Job: E1, S1, R2 (+ R3/E3/S2 за наявності named-відгуку). Персона: переглядає Secondary, job задовольняється для Primary.
  • Контакт
    • Контактна формаглобальний contact.html
      Job: R4 — «бути одразу зрозумілою у своїй ролі», запускає Main. Персона: Primary і Secondary.

Глибина до Main job для Primary-персони — 1 клік (Головний → Контактна форма); межа — 3 кліки. Деталі — sitemap.md, розділ «Навігація».

Flows

Mermaid, той самий код, що в flows.md.

Flow 1 — Main job: «Дійти до реальної домовленості про експорт через перевіреного партнера»

flowchart TD
  Start(["Виноробня приходить на сайт, уже готова почати розмову"]) --> A["Головний"]
  A --> B{"Є бодай один named-відгук?"}
  B -->|Ні| C["Порожній стан: блок довіри без прикладу"]
  B -->|Так| D["Блок довіри з named-відгуком"]
  C --> E["Контактна форма"]
  D --> E
  E --> F["Обирає роль «Виноробня», заповнює поля"]
  F --> G{"Усі обов'язкові поля коректні?"}
  G -->|Ні| H["Помилка: підсвічені поля форми"]
  H --> F
  G -->|Так| I["Завантаження: заявка надсилається"]
  I --> J{"Заявка дійшла успішно?"}
  J -->|Ні| K["Помилка: сервіс недоступний"]
  K --> L{"Пробує ще раз?"}
  L -->|Так| I
  L -->|Ні| M(["Тупик: виноробня йде з сайту, не достукавшись"])
  J -->|Так| N["Контактна форма: підтвердження отримано"]
  N --> O["Куратор зв'язується особисто — поза сайтом"]
  O --> P(["Main job закрито: реальна домовленість про експорт"])

Розвилки

  • B — є бодай один named-відгук
  • G — усі поля коректні
  • J — заявка дійшла успішно
  • L — пробує ще раз після збою

Стани

  • Empty — C: немає named-відгуку
  • Error — H, K
  • Loading — I
  • Тупик — M

Flow 2 — R1: «Звузити вибір до реально підходящих партнерів»

flowchart TD
  Start(["Імпортер шукає виноробню під свій ринок"]) --> A["Головний"]
  A --> B["Список виноробень"]
  B --> C["Завантаження: список виноробень"]
  C --> D{"Список завантажився?"}
  D -->|Ні| E["Помилка: каталог недоступний"]
  E --> E1{"Пробує ще раз?"}
  E1 -->|Так| C
  E1 -->|Ні| F(["Тупик: імпортер іде з сайту"])
  D -->|Так| D1{"Чи є хоч одна виноробня в каталозі?"}
  D1 -->|Ні| D2["Порожній стан: каталог ще порожній"]
  D2 --> D3(["Тупик: немає кого показати, іде з сайту"])
  D1 -->|Так| G["Обирає фільтри: регіон, сорт, сертифікати"]
  G --> H{"Фільтри повертають результати?"}
  H -->|Ні| I["Порожній стан: немає виноробень за цими фільтрами"]
  I --> J{"Пробує ширші фільтри?"}
  J -->|Так| G
  J -->|Ні| K(["Тупик: іде з сайту, не знайшовши"])
  H -->|Так| L["Переглядає список карток"]
  L --> M0["Завантаження: картка виноробні"]
  M0 --> M1{"Картка завантажилась?"}
  M1 -->|Ні| M2["Помилка: картку не вдалось відкрити"]
  M2 --> M3{"Пробує ще раз?"}
  M3 -->|Так| M0
  M3 -->|Ні| M4(["Тупик: не побачила деталей, іде з сайту"])
  M1 -->|Так| M["Картка виноробні"]
  M --> N{"Критерії й відгуки переконують?"}
  N -->|Ні| O{"Повертається до списку?"}
  O -->|Так| L
  O -->|Ні| P(["Тупик: іде з сайту, не переконавшись"])
  N -->|Так| Q["Контактна форма"]
  Q --> R(["R1 закрито: лишає заявку під конкретну виноробню"])

Розвилки

  • D, E1 — завантаження й повтор
  • D1 — холодний старт каталогу
  • H, J — фільтри й повтор
  • M1, M3 — картка й повтор
  • N, O — переконує / повернутись

Стани

  • Empty — D2, I
  • Error — E, M2
  • Loading — C, M0
  • Тупики — F, D3, K, M4, P

Flow 3 — R2: «Зрозуміти, що партнера вже хтось перевірив»

flowchart TD
  Start(["Імпортер потрапляє на сайт уперше"]) --> A["Головний"]
  A --> A1["Завантаження: блок довіри"]
  A1 --> B{"Чекліст критеріїв відбору завантажився?"}
  B -->|Ні| C["Помилка: блок довіри не показано"]
  C --> C1{"Пробує ще раз?"}
  C1 -->|Так| A1
  C1 -->|Ні| D(["Тупик: не бачить доказу відбору, іде з сайту"])
  B -->|Так| E{"Чекліст конкретний: назви критеріїв і цифри є?"}
  E -->|Ні| F["Порожній стан: лише загальні слова без критеріїв"]
  F --> G(["Тупик: не довіряє методології, іде з сайту"])
  E -->|Так| H["Список виноробень"]
  H --> H1{"Чи є хоч одна виноробня в каталозі?"}
  H1 -->|Ні| H2["Порожній стан: каталог ще порожній"]
  H2 --> H3(["Тупик: довіряла методології, але нема кого показати"])
  H1 -->|Так| I0["Завантаження: картка виноробні"]
  I0 --> I1{"Картка завантажилась?"}
  I1 -->|Ні| I2["Помилка: картку не вдалось відкрити"]
  I2 --> I3{"Пробує ще раз?"}
  I3 -->|Так| I0
  I3 -->|Ні| I4(["Тупик: не побачила деталей, іде з сайту"])
  I1 -->|Так| I["Картка виноробні"]
  I --> J{"Ця виноробня відповідає показаним критеріям?"}
  J -->|Ні| K{"Пробує іншу картку?"}
  K -->|Так| H
  K -->|Ні| L(["Тупик: довіряла методології, але жодна картка не підійшла"])
  J -->|Так| M["Контактна форма"]
  M --> N(["R2 закрито: довіряє рекомендації без додаткової перевірки"])

Розвилки

  • B, C1 — завантаження й повтор
  • E — чекліст конкретний
  • H1 — холодний старт каталогу
  • I1, I3 — картка й повтор
  • J, K — відповідає / інша картка

Стани

  • Loading — A1, I0
  • Error — C, I2
  • Empty — F, H2
  • Тупики — D, G, H3, I4, L
