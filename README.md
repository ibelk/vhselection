# VH Selection

Репозиторій продукту VH Selection. Опис продукту та робочі правила
репозиторію — у [CLAUDE.md](CLAUDE.md).

## Артефакти

- [index.html](index.html) — стартова сторінка
- [CLAUDE.md](CLAUDE.md) — опис продукту та правила репозиторію
- [research/](research/) — дослідження (наповнюється на уроці, якому знадобиться)
- [research/research.md](research/research.md) — зведення дослідження (конкуренти, бенчмарк, патерни, висновки)
- [research/research.html](research/research.html) — те саме зведення як сторінка з навігатором
- [personas.md](personas.md) — реєстр персон (primary позначена)
- [research/notes/jtbd.md](research/notes/jtbd.md) — jobs to be done та JTBD-матриця
- [personas.html](personas.html) — персони й jobs як сторінка з навігатором
- [sitemap.md](sitemap.md) — реєстр сутностей і екранів продукту (головний екран позначено)
- [flows.md](flows.md) — user flows (Mermaid): main job і ключові related jobs
- [ia.html](ia.html) — знімок IA (sitemap деревом, flows, матриця трасування) як сторінка з навігатором
- [wireframes/_conventions.md](wireframes/_conventions.md) — правила вайрфреймів: рамка, розмітка, назви файлів, стани
- [wireframes/home.html](wireframes/home.html) — вайрфрейми продукту (усі 4 екрани й стани, сірим, у рамці `.device`)
- [microcopy.md](microcopy.md) — інвентар тексту інтерфейсу (ключ, екран, зона, рядок)
- [voice.md](voice.md) — голос продукту: принципи, словник термінів і дій, заборонене, правила мікрокопі за типом елемента
